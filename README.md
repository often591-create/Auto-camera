# Auto Camera 📷

原生安卓相机 App：依照手机的镜头硬件与现场环境，帮你决定用几倍、怎么拍。
国内版与国际版安卓手机都能用（不依赖谷歌服务）。

## 第一阶段（已完成）
- **镜头硬件读取**：用 Camera2 读出每颗后镜头的焦距、传感器尺寸、光圈、像素，自动换算成倍数按钮；
  被厂商隐藏的镜头用机型库补上。机型同时比对型号代码与市场名称，国内版、国际版都认得。
- **拍照**：点击对焦、曝光滑杆、双击取消对焦、双指缩放、闪光灯（自动／开／关／常亮）、
  定时 3s／10s、比例 4:3／16:9／1:1／全屏、网格线、前后镜头、长按快门连拍、音量键拍照。
- **模式**：拍照、人像、夜景、录像、专业。人像和夜景使用厂商开放的 CameraX 扩展，手机不支持会自动隐藏。
- **专业模式**：ISO、快门、白平衡、手动对焦，实时显示当前参数。
- **录像**：1080p／4K、30／60 fps。
- **设置**：画质、分辨率、录像规格、音量键、快门声、保存位置、镜头信息。

## Auto Camera 助手（独立 APK）
配合手机自带相机使用，不用 root：
- **悬浮窗**：可拖动的小圆球，点开显示倍数建议（依场景、距离与你手机的镜头）；不挡操作的网格、水平仪、俯拍水平。
- **滤镜**：街头黑白、正片、自然人像、清透、经典浓郁、胶片暖调、柔光（名称为自取，不使用相机品牌商标）。
- **水印**：白边或角落小字，可选型号、参数、日期，不放品牌标志。
- **处理方式**：从相册挑照片、在相册里分享给助手，或开启自动处理（系统相机拍完自动另存一份）。原片不动。

到 [Releases](../../releases) 下载最新的 `AutoCamera-xx.apk`。每次推送到 `main` 都会自动编译。

## 自己编译
```bash
gradle assembleRelease
```
需要 JDK 17、Android SDK 35、Gradle 8.11。
